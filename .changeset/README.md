# Changesets

Each Markdown file here describes a change to `@istec/grid-core` and/or `@istec/grid-ui` and its semver bump. Add
one with `pnpm changeset`. Both packages share one version (`fixed` in `config.json`); private apps under `apps/*`
are never versioned or published. See [CONTRIBUTING.md](../CONTRIBUTING.md) for the release flow.
